# BukiLauncher
<img width="377" height="316" alt="BukiLauncher" src="https://github.com/user-attachments/assets/d2ef5436-3a0a-4303-a1df-74827cd2adc9" />

BukiLauncher is a Minecraft launcher made in Python.

## Features
- Mod manager
- Fabric, Forge, NeoForge and Quilt support
- Multi-language support
- UUID and JVM arguments editing feature
- Light and dark themes

## Installation
BukiLauncher is portable. Extract the archive and run `BukiLauncher.exe`.
